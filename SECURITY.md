# Security Policy

## Supported hulls

| Version | Supported |
| --- | --- |
| 2.x | Yes |
| 1.x | No — pre-refit, sailed by the old shipyard rig |

## Reporting a hole below the waterline

Signal the Quartermaster privately through GitHub Security Advisories. Do not open a
public issue for anything that could sink the fleet.

## Deck rules

- No credentials in commits, ever. What goes in the bilge stays in the bilge — even after
  you scrub the deck, the water underneath remembers.
- Release rigs run on the dockside build fleet, not on this repository.
- Build manifests are published with every sailing so the fleet can verify what shipped.
